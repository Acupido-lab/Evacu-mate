EvacuMate Access Guide

Relief & Shelter Helper

This guide explains how to access and run EvacuMate in both Offline and Online environments.

1. 📴 Offline Access (No Internet Required)

🌟 Permanent Offline Link (Never Changes on Any Device)

No more searching for changing IP addresses. EvacuMate broadcasts its own permanent local domain across your shelter's Wi-Fi router or phone mobile hotspot:

http://evacumate.local:8550

Also accessible as http://evacumate.local (via Port 80 auto-redirection).

Device Compatibility:

  • iPhone & iPad: Native mDNS support in Safari and Chrome.
  • Android (12, 13, 14, 15+): Native mDNS resolution in Google Chrome.
  • Windows & Mac: Works out of the box in Chrome, Edge, and Safari.
  • Host Computer: http://evacumate.local:8550 or http://127.0.0.1:8550.

📱 Instant Mobile Camera QR Code

On your laptop, click the 📱 Connect Mobile button in the top navigation bar. Any volunteer can point their phone camera at the screen to open EvacuMate immediately—zero typing!

📲 Install as an App on Phones & Tablets (PWA)

When opened in Chrome on Android or Safari on iOS, tap the browser menu (⋮ or Share) and select "Add to Home Screen" / "Install App". EvacuMate will run full-screen like a native mobile app with complete offline caching!

2. 🌐 Permanent Public Online Runtime Gateway (Fixed Public URL)

Give EvacuMate a single fixed public URL that never changes, never expires, and auto-reconnects on Windows boot.

The 6 Golden Gateway Rules:
  • 1. Single Fixed Domain: Binds to ONE permanent reserved domain only.
  • 2. Preserved Across Reboots: Identical URL across restarts, reboots, and updates.
  • 3. No Temporary Links: Zero random subdomains.
  • 4. Boot Auto-Reconnect: Automatically re-establishes the tunnel on system boot.
  • 5. Global Reach: Reachable from any gadget (iPhone, Android, tablet, PC) globally.
  • 6. HTTPS Enforced: SSL/TLS encryption enabled by default.

Quick 3-Minute Setup:

  1. Claim Free Lifetime Domain: Log in to dashboard.ngrok.com/domains and claim your 1 free permanent static domain (e.g. mysite.ngrok-free.website or shelter.ngrok-free.app).
  2. Get Your Authtoken: Copy your token from ngrok Authtoken page.
  3. Configure Gateway: Double-click configure_gateway.bat (or EvacuMate Permanent Gateway on Desktop) to save your domain and token.
  4. Enable Boot Auto-Reconnect: Press option [4] in the menu to install silent background auto-start on Windows boot!

Alternative: 24/7 Cloud Hosting on Render.com

If you want EvacuMate online even when your PC is turned off:

  1. Push this workspace folder to your GitHub Repository (https://github.com/Acupido-lab/Evacu-mate.git).
  2. Log into Render.com and click New Web Service.
  3. Connect your repository (uses render.yaml & Procfile).
  4. Render provides a 24/7 permanent URL like https://evacumate-relief-helper.onrender.com.

3. 💾 Data & Backup

All records (evacuees, families, supplies) are stored in database/evacumate.db locally on your hard drive, ensuring complete data security and offline survival.

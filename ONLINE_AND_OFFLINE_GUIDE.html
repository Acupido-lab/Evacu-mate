EvacuMate Access Guide

Relief & Shelter Helper

This guide explains how to access and run EvacuMate in both Offline and Online environments.

1. 📴 Offline Access (No Internet Required)

Mode A: Local Computer (Single User / Admin)

1. Double-click the EvacuMate App shortcut on your Desktop.

2. The application will start and open automatically at:
http://127.0.0.1:8550 or http://localhost:8550

Open EvacuMate Local Server

Mode B: Local Wi-Fi / LAN Network (Shelter / Multi-Device)

Connect multiple phones, tablets, or laptops in your shelter or office without internet!

How to connect other devices on the same Wi-Fi:
  1. Start EvacuMate on your host computer.
  2. Note your Network IP shown in the terminal (e.g., http://192.168.1.15:8550).
  3. On any phone or laptop on the same Wi-Fi, open the browser and navigate to http://<YOUR-LOCAL-IP>:8550.

2. 🌐 Online Access (Public Internet Access)

Free 24/7 Cloud Hosting on Render.com

Deploy your system online so anyone can access it globally:

  1. Push this workspace folder to a GitHub Repository.
  2. Log into Render.com and click New Web Service.
  3. Connect your GitHub repository. (Render uses render.yaml & Procfile automatically).
  4. Get your permanent live URL (e.g., https://evacumate.onrender.com).

3. 💾 Data & Backup

All records (evacuees, families, supplies) are stored in database/evacumate.db locally on your hard drive, ensuring complete data security and offline survival.
